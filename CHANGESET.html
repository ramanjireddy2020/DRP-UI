Why no phase component changed

TxKG, LitMineX, CurateX, ScreenSuite and NovSearch total roughly 5,100 lines and all five advance the workflow by calling setActiveStep(n) then setWorkflowPhase("x-loading"). None of them needed editing, because the phase string already says which module owns it: 

// CompleteWorkflow.jsx — setWorkflowPhase resolves the owning moduleconst owner = moduleForPhase(phase);if (owner.key === activeKey) {  setPhase(phase);            // same module — just advance it} else {  activateModule(owner.key, { phase });  // different module — activate it}

So a child calling setWorkflowPhase("litminex-loading") activates LitMineX on its own. setActiveStep became navigation-only, and in the pair above it is a harmless no-op — the module is not yet visited, so the phase call does the real work. Correct order of events, no call-site changes.
